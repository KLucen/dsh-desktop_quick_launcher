# dsh-desktop_quick_launcher v0.2.6

**桌面一键启动 / 一键重启 / 优雅退出** 的 DSH Web 插件，并且**绝不切断正在生成的回答**。独立重建自已退役的 `@linxin666/dsh-desktop-launcher`（Apache-2.0）。

An independent, Apache-2.0 rebuild of the retired `@linxin666/dsh-desktop-launcher`:
a double-click desktop icon that starts `dsh web` and opens an **authenticated** Web GUI URL, a
floating panel that rebuilds the shortcut / restarts the service / exits gracefully, and a
Settings card for the panel's buttons and the plugin's own logs.

## 安装 / Install

```bash
# GitHub（推荐）
dsh plugin --profile web add github:KLucen/dsh-desktop_quick_launcher
# 镜像（github.com 不可达时）
dsh plugin --profile web add "https://gh-proxy.com/https://codeload.github.com/KLucen/dsh-desktop_quick_launcher/tar.gz/refs/heads/main"
# 固定到本版本
dsh plugin --profile web add "https://gh-proxy.com/https://codeload.github.com/KLucen/dsh-desktop_quick_launcher/tar.gz/v0.2.6"
```

升级后**不需要任何手动操作**：宿主每次启动都会重写已有的 `launcher.ps1`，现有桌面快捷方式自动跟上。

## 本版新增 / Added in this release

- **一键重建桌面快捷方式**：点右下角启动器按钮打开详情面板，顶部即「桌面快捷方式」一节；快捷方式缺失时以黄色警示 + 主色高亮按钮提示，点一下即可重建。设置卡片里也有同一按钮。
- `GET /status` 新增 `shortcut { name, path, exists }`，界面能**主动发现**快捷方式被删除。

## 本版修复 / Fixed in this release

- **删除快捷方式后无法从界面恢复**：0.2.2 起图标按钮改为"打开详情"，`onCreate`（生成快捷方式）成为死代码 —— UI 上不再有任何生成入口。现已补回并放在用户期望的位置。
- `package.json` 版本号与代码内 `PLUGIN_VERSION` 不一致（显示 0.2.5、运行时自称 0.2.6），已同步。

## 有意不做 / Deliberately not done

- 开机**不**自动重建快捷方式：否则"我故意删掉图标"每次重启都会长回来。语义是——删了就是删了，但界面会提示你，一键可恢复。

## 验证 / Verified before release

- 在真实实例上复现了删除场景：`DSH-Web.lnk` 确实不存在 → `POST /create` → 200 → 重建出的 `.lnk` 指向
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File <scripts>\launcher.ps1`。
- `pnpm typecheck` 通过；`pnpm test` **49/49**。
- 前几版的关键路径（就绪门、token 流程、计划任务助手、nonce、busy 阻断）已分别实测：
  - 探针分支：`up-dsh` / `starting`（ping 200 但 `/` 仍 404 的启动窗口）/ `down` 均符合预期；
  - token 流程：无 cookie 裸 origin → 401，token URL → 303 + Set-Cookie，跟随 → 200（含 `__DSH_BOOT__`），刷新 → 200；
  - 重启：计划任务助手完整跑通（约 16–21 秒到就绪），且"助手从未启动"时会取消重启、服务保持运行。

## 已知限制 / Known limitations

- 重启与退出会终止整个 `dsh web` 进程；会话可恢复，但**当前正在生成的回答不会被保留**（这正是插件在回合未结束时拒绝执行的原因）。
- busy 检查依赖 live session store；若该服务缺失或 API 变化则**放行**并在 `busyCheck` 记录原因（fail-open，避免重启永久失效）。
- nonce 只挡跨站浏览器请求，挡不住本机进程。
- 所有路由仅限回环；对暴露到局域网的实例，远程浏览器无法使用。
- Windows 生成的图标固定名 `DSH-Web.lnk`，会覆盖桌面上的同名快捷方式。
- POSIX 启动器由同一模板生成，但只在 Windows 上验证过；重启助手仅支持 Windows。
